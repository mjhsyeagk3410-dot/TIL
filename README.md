# TIL

오늘 배운 것 목차
1. 터미널을 왜 쓰고, 왜 사용하는지 
2. Git과 GitHub가 무엇이고 왜 쓰는지
ㄴ Git의 필수개념, Git의 핵심 명령어, 
3. 터미널을 이용해 Git 설치하는 법 
4. 터미널을 이용해 VS Code 설치하는 법 
5. 터미널을 파워셀에서 Git bash로 바꾸는법
6. 터미널에서 사용하는 셀 문법

1. 터미널을 쓰는 이유는, 일단 터미널을 통해서 소프트웨어를 설치하는것을 주로배웠다. 왜 이렇게 해야하는가? 풀스택엔지니어라면 앞으로 터미널로 프로그램을 설치도 하고 삭제도 하고 모든걸 터미널로 할 수 있어야한다
2. Git은 버전관리시스템(VCS)이고, 분산형(DVCS)이다. 단점은 극단적으로 어렵다. 필수명령어가 140개에다가 다양한 옵션선택이 있기 때문이다.
3. GitHub는 일종의 웹서비스, 원격저장소, 호스팅업체라고 할 수 있다. 주로 협업하기가 좋은 서버이며 개발자 포트폴리오로도 활용이 가능하다.
4. GitHub는 없어도 Git은 쓸 수 있다. 내가 쓴 이 코드를 공유할 수단이 없어질뿐이다.
5. Git의 필수개념은, 3가지영역으로 살펴봤을때 워킹 디렉토리, 스테이징에리어, 리포지토리가 있다.
6. 오늘 배워본 Git 핵심 명령어는, add, commit, push, pull, git reset, git revert, switch -c, checkout -d를 배웠다.
7. 터미널을 이용해 Git를 설치할때는, winget 명령어를 먼저 쳐야한다.
8. winget search git 명령어를 치고, 그리고 winget install -i Git.Git 이렇게 치면서 git이 설치가 된다.
9. vscode도 이런식으로 설치를한다
10. 그리고 터미널은 기본적으로 파워셀이다. 근데 앞으로 우리는 터미널 설정에서 기본프로필에 파워셀로 되어있는데, 그 파워셀을 git bash로 바꾸기. 우리는 이것으로 일단 쓸 것.
11. 그리고 터미널에서 사용하는 셀 문법 배운것을 정리해본다.

리눅스 문법의 개념
d = 디렉토리(폴더)
l = 링크
30 = 파일사이즈
r = 읽을수있는권한
w = 쓸수있는 권한
x =  실행할수 있는 권한 
rwx = 소유자의 권한
rwxrwxrwx = 소유자 권한, ?권한,다른사람권한이 모두 있는것으로 곧 자기자신 오너폴더, 파일이라는 의미
admin = 소유자

exit : 터미널을 끌때 x를 누르는게 아니라, exit명령어를 치면 꺼진다. 
pwd : 현재 내 위치를 알 수 있다.
ls : 해당 위치에 있는 디렉토리들을 확인할 수 있다 (대충)
clear : 100개의 명령어를 썼을때 이걸 모두 지울 수있다
ls -al : 해당 위치에 있는 디렉토리들을 확인할 수 있다. (모든것)
cd.. : 상위 폴더로가기
history : 지금까지 쓴 명령어가 모두 나온다 
cd ~ : 홈디렉토리로 이동한다
cd - : 이전폴더로 돌아가기
code . : 코드로 현재 파일을 열때
echo : 뒤에 쓴 텍스트가 메아리처럼 출력되는것
touch : 뒤에 생성하고 싶은 파일 이름을 쓰면 그 파일을 생성한다 
echo $SHELL : 이건 무슨 명령이였는지 까먹음 
mkdir : 뒤에 생성하고 싶은 폴더 이름을 쓰면 그 폴더가 생성된다
cd 폴더이름: 그 폴더로 들어간다
cat 파일이름: 그 파일에 저장된 텍스트를 불러온다 

echo 명령어의 활용/쓰임새
echo "Hello World" > README.md 를 칠 경우? README.md 파일에 Hello World 텍스트가 저장이 된다 
echo "Bye Bye Wirkd" >> README.md 라고 하면 Hello World 다음 줄에 이 텍스트가 저장이 된다 
곧 터미널을 이용해 해당 파일의 텍스트를 쳐서 저장을 할 수 있다는것이다. 


단축키같은경우는, 
ctrl + u : 현재 쓴 명령어를 지우고 싶을때
ctrl + w : 현재 쓴 명령어 중 워드 단위로 지우고 싶을때
