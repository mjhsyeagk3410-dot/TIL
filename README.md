1. 터미널을 쓰는 이유는, 일단 터미널을 통해서 소프트웨어를 설치하는것을 주로배웠다. 왜 이렇게 해야하는가? 풀스택엔지니어라면 앞으로 터미널로 프로그램을 설치도 하고 삭제도 하고 모든걸 터미널로 할 수 있어야한다
2. Git은 버전관리시스템(VCS)이고, 분산형(DVCS)이다. 단점은 극단적으로 어렵다. 필수명령어가 140개에다가 다양한 옵션선택이 있기 때문이다.
3. GitHub는 일종의 웹서비스, 원격저장소, 호스팅업체라고 할 수 있다. 주로 협업하기가 좋은 서버이며 개발자 포트폴리오로도 활용이 가능하다.
